A RuneScape 3 client plugin for planning Necromancy rituals: choose a ritual, focus, site, glyphs and gear, and see what the rituals use and make, what they cost, how long they take and the experience they give. It's a port of the [Necromancy Ritual Calculator](https://github.com/duke605/necromancy-ritual-calculator) web app to the in-game [plugin API](https://developer.runescape.com/rs/getting-started.html).

Plugins are written in Lua 5.4 and run inside the game client. Development needs Lua 5.4, StyLua and lua-language-server.

## Setup

1. Join the plugin beta world and find the beta client's `dev_plugins` folder, as described in [Accessing the API](https://developer.runescape.com/rs/tutorial/1helloworld.html).
2. Link its `ritualist` folder to this repo's `plugin/` folder (a directory junction on Windows, a symlink elsewhere).
3. In the game, open the console with ALT+` and enable the plugin:
   ```
   prf
   pon ritualist
   ```

After changing code, run `prl ritualist` in the console to reload.

## Commands

| Command        | Description                                                     |
| -------------- | --------------------------------------------------------------- |
| `make test`    | Runs the tests for the pure-Lua modules (needs `lua5.4`).        |
| `make check`   | Syntax-checks every Lua file.                                   |
| `make fmt`     | Formats the Lua with StyLua.                                    |
| `make lint`    | Checks formatting and runs lua-language-server diagnostics.     |
| `make package` | Builds `dist/ritualist-<version>.zip` for upload to Mod.io.     |
| `make data`    | Regenerates `plugin/src/data/` from the web app's JSON (set `NRC` to a local checkout to skip cloning). |

## Console commands

| Command                 | Description                                         |
| ----------------------- | --------------------------------------------------- |
| `prf`                   | Rescans for plugins after adding one or editing its manifest. |
| `plist`                 | Lists the plugins found.                            |
| `pon` / `poff <name>`   | Enables or disables a plugin.                       |
| `prl <name>`            | Reloads a plugin.                                   |
| `ppe <name> httpAccess` | Grants a permission, for testing the price lookups. |

## Project structure

| Path                  | Contents                                                                 |
| --------------------- | ------------------------------------------------------------------------ |
| `plugin/`             | The plugin itself. Only this folder is linked and packaged.              |
| `plugin/plugin.json`  | The manifest: name, version, contact email, permissions and URLs.        |
| `plugin/main.lua`     | The entry point, run when the plugin is enabled.                         |
| `plugin/src/`         | Modules, loaded with `require("src/...")` relative to `plugin/`.         |
| `plugin/src/ritual.lua` | The ritual maths. Pure Lua with no client API, so it can be tested.     |
| `plugin/src/data/`    | Ritual, glyph, ink, item and equipment data, generated by `make data`.   |
| `plugin/src/ui/`      | Interface components.                                                    |
| `plugin/resources/`   | Images (`.png`, up to 1024×1024) and audio (`.ogg`), read through `Plugin.resources`. |
| `tests/`              | Tests, run outside the game with `make test`.                            |
| `types/`              | Editor stubs for the client API, for lua-language-server.                |
| `scripts/`            | The data and packaging scripts.                                          |
| `docs/`               | The README's logo.                                                      |

## Before submitting

- Set `contactEmailAddress` in `plugin/plugin.json`. It's shown to users, so Jagex recommends using a different address from your Mod.io login.
- Follow the [plugin guidelines](https://developer.runescape.com/rs/submission/guidelines.html) and the [submission process](https://developer.runescape.com/rs/submission/process.html). The Mod.io description must cover the email, the EULA, each permission and data protection.
